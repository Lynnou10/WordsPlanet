# La Planète des Mots — V1.1

V1.3 avec uniquement **Lettres** et **Sons**. Les catégories Syllabes, Mots et Phrases sont totalement retirées de l'interface.

- Lettres : 26 groupes × 10 exercices.
- Sons : 22 groupes × 10 exercices.
- 48 récompenses illustrées locales dans `img/`.
- Thèmes : dinosaures, Formule 1/course, chiots héros, monde de blocs, extraterrestres/espace, chevaliers, robots et créatures à collectionner.
- Chaque groupe terminé débloque une récompense.
- Bouton Admin pour réinitialiser la progression.

Les univers de franchises ont volontairement été adaptés en thèmes génériques pour que le dépôt Git puisse contenir ses propres illustrations sans republier des assets propriétaires.

## GitHub Pages
Décompresser le ZIP à la racine du dépôt puis activer Pages sur `main` / `/ (root)`.


Les illustrations de dinosaures ont été corrigées pour distinguer clairement les espèces, notamment le Tricératops (collerette et trois cornes) et le Stégosaure (plaques dorsales et pointes caudales).

V1.3 : l'écran d'accueil est désormais construit explicitement avec seulement deux catégories : Lettres et Sons. Aucun ancien module n'est généré puis masqué.
